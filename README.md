# kravidb

Relational database storage engine with B-Tree indexing built with C++23 Modules and `xmake`.

## Requirements

- C++23 compiler (`clang++` 17+ or `g++` 14+)
- [xmake](https://xmake.io) 2.8+

## Quick Start

```bash
# Build the project
xmake

# Run the database binary
xmake run kravidb
```
